# Agent evals (M3-03)

Generated by `npm run eval:agent` from recorded traces. Offline: no key, no network, no database. Regenerate and diff with `npm run eval:agent && git diff --exit-code docs/evidence/agent-evals.md`.

What it proves: the agent's guardrails (input limits, typed Qloo parameters, schema-validated output, names must come from the booker's sentence, the grounding check and the template fallback) hold against the recorded behaviour of a real model and against hand-written stand-ins for a model that obeys an injection. What it does not prove: that a model will never misbehave on a sentence nobody recorded; the guardrails, not the model, are what is tested.
