# ADR 0005: Next.js App Router, server components for slate pages

Status: Accepted (2026-10-24, owner Approval 2)

## Context
Design criterion; WCAG 2.2 AA, mobile-first.

## Decision
Server components for slate and detail; a client island for intake. Every screen has loading, empty and error states. Tokens in one CSS file. Plain-text rendering of all generated and third-party strings.

## Alternatives rejected
SPA.

## Consequences / cost to reverse
Low.
